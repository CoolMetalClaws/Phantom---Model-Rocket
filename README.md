## Description 

A high soaring model rocket pushing the boundaries of a C sized motor, with a weight of just 10g, and a simulated apogee of 508m! Haven't heard of model rocketry before? Model rockets are miniature scale rockets designed to fly using commercially available black powder engines! This is my second model rocket, with my first soaring up 386m! This rocket is designed to test the upper bounds of a C sized rocket engine and achieve astonishing heights with a generic motor. An altimeter will be placed inside the rocket to gather flight data and capture the rocket's apogee.

## Why i built this!

This project has always been one at the back of my mind, a curiosity to see how far can i push a C-Size motor, and how can i improve the design of my old rocket and retain only the good features. After a short break from rocketry as a hobby, i am back with another design that i hope can outperform all C-size model rockets! (Pretty unrealistic but the design is promising.)
